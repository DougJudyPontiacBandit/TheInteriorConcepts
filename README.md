# The Interior Concepts

A Vue 3 website with an Express backend for The Interior Concepts.

## Run locally

```sh
npm install
npm run dev
```

Open the Vite URL printed in the terminal (usually `http://localhost:5173`).
The contact form submits inquiries to Formspree (`xppqraej`).

## Production

```sh
npm run build
npm start
```

The Express server serves the built website. Set `PORT` to choose a different
server port.
